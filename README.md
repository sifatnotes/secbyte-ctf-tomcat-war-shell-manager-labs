## Learning Path

A practical progression through these **hands-on cybersecurity labs**:

1. Start with **Tomcat Launchpad** to establish the basic Tomcat investigation workflow.
2. Continue with **Tomcat Vault Recon** and **Tomcat Shadow Trail** for reconnaissance and artifact discovery.
3. Explore **Tomcat Credential Crunch** to understand the importance of protecting application credentials and configuration data.
4. Study **Tomcat Manager Break-In** before moving into WAR deployment concepts.
5. Continue with **WAR Dropper** and **WARcraft Deploy** to understand application deployment security.
6. Explore **WAR Room: Tomcat Takeover** and **Tomcat Manager WAR Path to Root** for more advanced Tomcat security scenarios.
7. Practice shell concepts with **Catching Reverse Shells** and **Tomcat Shellcraft**.

Difficulty levels are not inferred unless explicitly stated in the supplied lab information.

## How to Use the Labs

1. Open a lab using its direct URL.
2. Read the objectives and environment requirements.
3. Use only the supplied CTF or an explicitly authorized security-testing environment.
4. Perform reconnaissance before making assumptions about the target.
5. Document services, application paths, credentials-related findings, and configuration weaknesses.
6. Analyze the security impact of each finding.
7. For defensive learning, consider how Tomcat Manager, WAR deployment, credentials, and shell activity could be detected or restricted.
8. Record remediation ideas alongside your technical notes.
